# ADR-0010: 사용자의 Mac에서 launchd로 상시 실행한다

- 상태: 채택
- 날짜: 2026-10-12

## 맥락

먼저 말을 거는 기능이 있으려면 봇이 계속 실행되고 있어야 한다. `claude` CLI는 구독 로그인 상태가 필요하다.

## 결정

사용자의 Mac을 호스트로 쓴다. Spring Boot 앱은 launchd로 상시 실행하고, PostgreSQL은 Docker로 띄운다.

## 결과

- 좋은 점: 이미 로그인된 `claude` CLI를 그대로 쓴다. 서버 비용이 없다.
- 나쁜 점:
  - Mac이 잠자기 상태이면 예약 작업이 실행되지 않는다. 깨어날 때 시간 창 안이면 놓친 작업을 실행한다.
  - 잠자기 방지 설정은 운영 가이드에서 다룬다.

## 검토한 대안

- 클라우드 VM이나 홈서버: 24시간 실행할 수 있지만, OAuth 토큰 관리와 운영 부담이 생긴다. 필요해지면 Docker 구성을 그대로 옮긴다.
