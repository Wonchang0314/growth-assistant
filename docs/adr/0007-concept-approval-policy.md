# ADR-0007: 개념 승인: 백필은 조건부 자동, 증분은 자동 + 안전장치

- 상태: 채택
- 날짜: 2026-10-12

## 맥락

수집이나 대화 중에 Claude가 새 개념을 제안한다. 모두 수동으로 승인하면 백필 때 부담이 크고, 모두 자동으로 승인하면 개념이 중복되거나 쪼개진다.

## 결정

- 초기 시드 개념: 사용자가 한 번 검토한다.
- 일회성 백필: 기존 개념의 `PART_OF` 하위이면서 Claude가 확신하는 개념은 자동으로 승인한다. 애매한 개념만 `#개념-관리`에서 묻는다.
- 정기 증분 동기화와 대화: 자동으로 승인하되, 안전장치 두 가지를 둔다.
  1. 이름이나 별칭이 같거나 거의 같은 기존 개념이 있으면 별칭으로 병합한다.
  2. 그 주에 자동 승인된 개념을 주간 리포트에서 되돌리거나 병합할 수 있게 보여준다.
- 승인 전 `PROPOSED` 개념에도 경험 카드는 연결한다. 다만 숙련도 추적과 출제 대상에서는 뺀다.

## 결과

- 좋은 점: 대량으로 들어오는 백필에서는 품질을 지키고, 이후에는 사용자 부담이 거의 없다.
- 나쁜 점: 자동 승인으로 품질이 서서히 떨어질 수 있어서, 사후 검토 습관이 필요하다.
