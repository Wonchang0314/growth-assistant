# ADR-0005: 임베딩 없이 통제 어휘 개념 태그로 검색한다

- 상태: 채택
- 날짜: 2026-10-12

## 맥락

대화와 출제에 관련된 경험 카드를 찾아야 한다. 임베딩을 쓰려면 임베딩 모델과 벡터 저장소가 필요하다. API 키를 쓰지 않으므로 임베딩은 로컬 모델로 만들어야 하고, PostgreSQL 기본 전문 검색은 한국어에 약하다.

## 결정

초기에는 임베딩을 쓰지 않는다. 개념을 통제 어휘(이름 + 별칭)로 관리하고, 수집할 때 Claude가 기존 개념 목록에서 골라 태그를 붙인다. 조회는 "개념 매칭 + 그래프 이웃 개념"으로 한다.

## 결과

- 좋은 점: 추가 인프라가 없다. 검색 결과의 이유를 설명할 수 있다. 숙련도·약점과 개념 단위로 바로 연결된다.
- 나쁜 점: 태그에 잡히지 않은 세부 내용은 찾지 못한다. 태그 품질이 추출 품질에 달려 있다.

## 재검토 조건

경험 카드가 수백 개 이상으로 늘고 "기록했는데 못 찾는" 경우가 잦아지면, `document_chunk`에 pgvector 컬럼을 더해 하이브리드 검색으로 확장한다.
