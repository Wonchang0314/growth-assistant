# ADR-0035: 원격 커스텀 커넥터는 Cloudflare 터널과 OAuth 2.1(CIMD, 구글 로그인)로 열고, HTTP는 Nest HTTP 어댑터로 띄운다

- 상태: 채택
- 날짜: 2026-10-20
- ADR-0014의 "HTTP 서버 없이 애플리케이션 컨텍스트만 띄운다"를 MCP HTTP 진입점에 한해 바꾼다(stdio 진입점과 CLI는 그대로 애플리케이션 컨텍스트). ADR-0018·0034가 원격 전환 때 새 ADR로 정하기로 한 항목(공개 경로·인증·IP 제한·알림·MCP Apps)을 정한다.

## 맥락

ADR-0034에 따라 모바일·아이패드에서 쓰려고 원격 커스텀 커넥터로 바꾼다. 커스텀 커넥터는 사용자 기기가 아니라 Anthropic 서버(외부 요청 대역 `160.79.104.0/21`)가 MCP 서버를 부른다. 그래서 서버는 인터넷에서 닿아야 하고, 주소를 아는 누구나 부를 수 있으므로 본인만 통과시키는 인증이 필요하다. 기기 단위로 막을 수는 없다. 사용자 기기가 직접 닿는 곳은 로그인 화면(`/authorize`)뿐이다.

조사([원격 전환·예약 작업 조사](../research/2026-10-19-remote-and-scheduling.md))에서 확인한 것: Claude는 OAuth 2.1의 CIMD를 기본 지원하고(등록 엔드포인트 없이 메타데이터 URL을 `client_id`로 씀), 고정 헤더 인증은 일부 조직의 베타다. Tailscale Funnel은 원래 접속 IP 전달이 확인되지 않았다. Tailscale Serve와 `mcp-remote`는 tailnet 안의 맥북 Desktop에서만 되고 모바일·클라우드 예약 작업에서는 닿지 않는다. 사용자는 도메인을 가지고 있다.

## 결정

1. **인증은 OAuth 2.1 인가 코드 + PKCE, 클라이언트 식별은 CIMD.** 우리 서버가 인가 서버(`/authorize`, `/token`)이자 자원 서버(`/mcp`)다. `client_id`는 허용 목록에 둔 Claude 메타데이터 URL만 받는다(SSRF 방지). 토큰 없는 `/mcp` 요청은 `401` + `WWW-Authenticate`(보호 리소스 메타데이터)로 답한다. 액세스 토큰은 짧게, 리프레시 토큰은 갱신마다 회전하고, 토큰은 해시로 저장한다.
2. **본인 확인은 구글 로그인(OIDC) + 이메일 허용 목록.** `/authorize`가 구글로 보내고, 돌아온 `id_token`의 `email_verified`와 이메일이 허용 목록과 같을 때만 Claude에 줄 인가 코드를 발급한다. 구글 토큰은 쓰지 않고 버린다. 구글 계정 패스키로 Face ID 로그인이 된다.
3. **공개 경로는 Cloudflare 이름 있는 터널.** 맥미니의 `cloudflared`가 밖으로 연결을 맺고, 앱은 `127.0.0.1`에만 바인딩한다. 사용자 도메인의 하위 도메인을 쓴다.
4. **IP 제한은 Cloudflare WAF 사용자 정의 규칙.** `/mcp`·`/token`은 Anthropic 대역에서 온 요청만 받는다. `/authorize`와 구글 콜백은 사용자 브라우저가 열므로 막지 않는다. 대역은 모든 Claude 사용자가 공유하므로 인증을 대신하지 못하고, 스캐너·봇을 맥미니 앞에서 거르는 보조다.
5. **HTTP는 Nest HTTP 어댑터(Express)로 통일한다.** OAuth 엔드포인트, `/healthz`, `/mcp`를 한 Nest HTTP 앱에 올린다. `/mcp`는 공식 Express 어댑터로 붙이고, `node:http`로 띄우던 지금 HTTP 서버를 대신한다. 도구 처리기와 유스케이스는 바뀌지 않는다(ADR-0018의 전송 분리).
6. **상시 실행은 LaunchAgent, FileVault는 유지한다.** 재부팅 뒤에는 사용자가 로그인해야 서버·터널·DB가 뜬다(`docs/ops.md`). 계획된 재시작은 `fdesetup authrestart`로 하고, 정전 뒤 멈춘 것은 헬스체크 알림으로 안다. 앱은 시작할 때 DB를 기다리고, 죽으면 `KeepAlive`가 다시 띄운다.
7. **운영 알림은 ntfy + 외부 헬스체크.** 인증 실패·작업 실패는 `AdminNotifier`의 ntfy 어댑터로 휴대폰에 보낸다. 서버가 죽으면 스스로 알릴 수 없으므로 외부 감시 서비스가 `/healthz`를 부른다.
8. **MCP Apps는 이번에 만들지 않는다.** 원격 커넥터로 바꾸면 모바일에서 MCP Apps를 쓸 길이 열린다. 퀴즈 화면(숙련도 3단계 색 표시 포함)은 6단계에서 만든다.

## 결과

- 좋은 점
  - 커넥터를 웹에서 한 번 붙이면 맥북·아이폰·아이패드와 클라우드 예약 작업에서 같은 서버를 쓴다.
  - CIMD라 클라이언트 등록·저장이 없고, 허용 목록으로 Claude만 토큰을 받는다. 비밀번호를 서버에 두지 않는다.
  - 포트 포워딩이 없고 집 공인 IP가 드러나지 않는다.
  - OAuth 컨트롤러가 Nest 모듈 구조에 맞고, 사용자가 Nest HTTP 계층을 익힌다.
- 나쁜 점·감수할 것
  - 인가 서버(메타데이터 2개, `/authorize`, 구글 콜백, `/token`, 토큰 저장·회전)를 직접 만들고 지킨다.
  - 구글과 Cloudflare 계정에 기댄다. 구글 로그인이 안 되면 원격에서 다시 로그인할 수 없다(발급된 토큰은 계속 동작).
  - Express와 MCP Express 어댑터 의존성이 늘고, 진입점마다 Nest 앱 형태가 다르다(HTTP 앱과 애플리케이션 컨텍스트).
  - 정전 뒤에는 맥 앞에서 로그인할 때까지 멈춘다.
  - 호스팅 앱의 CIMD `client_id` 값과 Claude가 쓰는 MCP 명세 개정은 첫 연결 로그로 확인해 허용 목록에 고정한다.

## 검토한 대안

- **OAuth + DCR:** 예제가 많지만 누구나 등록할 수 있고 클라이언트 행이 쌓인다.
- **고정 헤더 인증:** 코드가 가장 적지만 이 계정에서 쓸 수 있는지 불확실한 베타다.
- **인증 없음 + IP 제한·비밀 경로:** 대역은 공유되고 URL 비밀은 기록에 남는다.
- **비밀번호 로그인·직접 패스키:** 외부 의존이 없지만 비밀번호 보관이나 WebAuthn 등록 절차를 만들어야 한다. Apple 로그인은 Face ID가 기본이지만 Apple Developer Program(연 $99)이 필요하다.
- **Tailscale Funnel:** 무료이고 도메인이 필요 없지만 원래 접속 IP 전달이 확인되지 않아 IP 제한이 불확실하다.
- **Tailscale Serve + `mcp-remote`:** OAuth 없이 tailnet이 인증을 대신하지만 맥북 Desktop에서만 되고 모바일·클라우드 예약 작업에서 닿지 않는다.
- **`node:http` + SDK Node 어댑터:** 의존성이 가장 적지만 폼 파싱·라우팅을 직접 쓰고, 사용자는 Nest로 통일하기로 했다.
- **FileVault를 끄고 자동 로그인:** 정전 뒤 스스로 돌아오지만 도난 시 디스크 보호를 잃는다.
