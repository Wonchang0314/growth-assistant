# ADR-0004: PostgreSQL 단일 저장소, 그래프 DB를 쓰지 않는다

- 상태: 채택
- 날짜: 2026-10-12

## 맥락

개념 사이의 선수·포함·연관 관계를 표현하는 그래프가 필요하다. 개인 학습용이라 개념은 많아야 수천 개 수준이다.

## 결정

PostgreSQL 하나에 모든 상태를 둔다. 그래프는 `concept`과 `concept_edge` 테이블로 표현하고, 선수 지식 체인이나 근본 원인 탐색은 재귀 CTE로 조회한다. 그래프 접근은 `ConceptGraphRepository` 인터페이스 뒤에 둔다.

## 결과

- 좋은 점: 숙련도, 퀴즈, 경험 카드와 개념을 바로 조인할 수 있다. 운영할 저장소가 하나이고 정합성 관리가 단순하다. 재귀 CTE는 DB 학습 목표와도 맞는다.
- 나쁜 점: 깊고 복잡한 그래프 탐색이 필요해지면 쿼리가 복잡해진다.

## 검토한 대안

- Neo4j: 이 규모에서는 이점이 작고, 저장소 두 개의 정합성 문제와 운영 부담이 생긴다.
- Apache AGE: 필요해지면 인터페이스 뒤에서 교체할 수 있는 후보로 남긴다.
