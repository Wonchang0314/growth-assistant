# ADR-0009: 숙련도는 코드가 계산하고, 힌트 없는 응답만 인정한다

- 상태: 채택
- 날짜: 2026-10-12

## 맥락

LLM 튜터 연구를 보면, 가드레일 없이 AI를 쓴 그룹은 연습 점수가 올랐지만 AI 없이 본 시험에서는 오히려 성적이 떨어졌다(Bastani et al., PNAS 2025). LLM이 지식 상태를 직접 추적하면 일관성이 떨어진다는 연구도 있다.

## 결정

- 숙련도·약점 점수와 FSRS 일정은 Kotlin 코드가 결정적으로 계산한다. Claude는 서술형 채점과 오개념 태깅만 한다.
- 숙련도에는 힌트 없이, 찍지 않고 맞힌 응답만 정답으로 반영한다. 답을 낸 직후 확신도(확실·애매·찍음)를 받는다.
- 대화 결과로는 점수를 바꾸지 않는다. 혼란 신호는 출제 우선순위에만 반영한다.
- 오류 신고된 문제의 응답은 계산에서 뺀다.

## 결과

- 좋은 점: 숙련도가 실제 실력에 가깝고, 결과를 재현할 수 있으며 테스트할 수 있다.
- 나쁜 점: 확신도 버튼을 누르는 한 단계가 늘어난다.
