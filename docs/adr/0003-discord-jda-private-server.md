# ADR-0003: Discord 개인 서버를 인터페이스로, JDA를 사용한다

- 상태: 대체됨(ADR-0014)
- 날짜: 2026-10-12

## 맥락

튜터가 먼저 말을 걸어야 하고, 객관식·빈칸 문제와 이어지는 대화가 필요하다. 모바일에서도 쓸 수 있어야 한다.

## 결정

사용자와 봇만 있는 Discord 개인 서버를 쓴다. 채널은 `#복습-퀴즈`, `#튜터`(대화마다 스레드), `#리포트`, `#개념-관리`, `#관리`로 나눈다. 라이브러리는 JDA + jda-ktx를 쓴다.

## 결과

- 좋은 점: 버튼(객관식), 모달(빈칸·서술형), 스레드(대화 세션)를 모두 지원한다. 봇이 먼저 메시지를 보낼 수 있다.
- 나쁜 점:
  - 상호작용 응답은 3초 안에 보내야 해서 지연 응답 패턴이 필요하다.
  - 상호작용 토큰은 15분 뒤 만료되므로, 그 이후에는 봇 토큰으로 새 메시지를 보낸다.
  - DM에서는 스레드를 쓸 수 없어 개인 서버가 필요하다.

## 검토한 대안

- Telegram: 퀴즈 투표 기능은 있지만 입력 모달이 없다.
- 봇 DM만 사용: 스레드가 없어 대화 세션이 섞인다.
- Kord: Kotlin 네이티브지만 커뮤니티와 업데이트 속도가 JDA보다 약하다.
- discord.js를 별도 프로세스로: 프로세스 두 개와 그 사이 통신만 늘어난다.
