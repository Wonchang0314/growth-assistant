# ADR-0002: LLM은 `claude` CLI 서브프로세스로 호출한다

- 상태: 대체됨(ADR-0012)
- 날짜: 2026-10-12

## 맥락

사용자는 Claude 구독 사용량으로 운영하기를 원한다. API 키를 쓰는 SDK 호출은 별도 과금된다.

## 결정

모든 LLM 호출은 `claude -p --output-format json` 서브프로세스로 한다. 호출은 `ClaudeClient` 인터페이스 하나로만 지나간다. 다음 원칙을 지킨다.

- 전용 빈 작업 디렉터리에서 실행하고, `--setting-sources ""`와 `--strict-mcp-config`로 다른 설정을 격리한다.
- 도구는 기본적으로 끄고(`--tools ""`), 대화와 주제 탐색 호출에만 `WebSearch`, `WebFetch`를 허용한다.
- 구조화된 출력은 `--json-schema`를 쓰고, Kotlin DTO로 다시 검증한다.
- 동시 실행은 최대 2개로 제한하고, 모든 호출을 `llm_call_log`에 남긴다.

## 결과

- 좋은 점: 추가 비용이 없다. 웹 검색을 별도 구현 없이 쓸 수 있다.
- 나쁜 점: 호출마다 프로세스를 띄우는 비용과 지연이 있다. 사용량 한도를 평소 Claude Code 작업과 공유한다. CLI 옵션과 출력 형식이 버전에 따라 바뀔 수 있다(고정된 응답 샘플 테스트로 감지한다).

## 검토한 대안

- Anthropic API SDK: 구독을 쓸 수 없어 제외했다.
