# ADR-0008: 간격 반복은 FSRS, 복습 단위는 개념

- 상태: 채택
- 날짜: 2026-10-12

## 맥락

복습 일정을 계산할 알고리즘이 필요하다. 처음에는 SM-2를 검토했다. LLM이 문제를 계속 만들 수 있으므로, 같은 문제를 반복하면 문제를 외우게 될 위험이 있다.

## 결정

- 알고리즘은 FSRS를 쓴다. 공식 구현을 Kotlin으로 직접 포팅하고, 기본 파라미터로 시작한다. 포팅 결과는 py-fsrs 기준 값으로 검증한다.
- 복습 단위는 문제가 아니라 개념이다. 복습할 때마다 같은 개념의 다른 문제를 낸다.
- 하루 복습은 최대 10문제로 제한한다.

## 결과

- 좋은 점: open-spaced-repetition 벤치마크에서 SM-2보다 예측 정확도가 높다. 문제 암기를 막는다.
- 나쁜 점: FSRS는 원래 카드 단위로 설계되었다. 문제가 매번 바뀌면 난이도 편차가 생기는데, 이것은 감수한다. 직접 포팅해야 한다.

## 검토한 대안

- SM-2: 단순하지만 예측 정확도가 낮다.
- FsrsKt 라이브러리: GPL-3 라이선스라 직접 포팅을 택했다.

## 재검토 조건

복습 기록이 수백 건 쌓이면 사용자 기록으로 FSRS 파라미터를 최적화한다.
